# Alex.OS Portfolio (Vite + React + motion)
npm install && npm run dev
- Put your photo at `public/avatar.png`; edit all content in `src/data.js`.
- Windows: Welcome, Projects, Specs, Credentials, Resume, Mail + NEW Experience (`Experience.log`, icon: Recycle Bin / "Quick Tour").
- Motion primitives in `src/components/fx.jsx` (SmoothButton, CountUp, Stagger, TypeText) follow Smooth UI / Unlumen UI patterns.
- To use the real libraries: `npx shadcn@latest init`, then add components from their registries (see smoothui.dev and ui.unlumen.com docs for the exact `add` commands) and swap them in for the fx.jsx helpers.
